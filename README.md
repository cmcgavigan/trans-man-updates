# Focal - updates

Downloads for Focal (formerly Trans Man), a Ctrl+C+C translator for English, German, French and Italian.

Get the latest Focal.exe from [Releases](https://github.com/cmcgavigan/trans-man-updates/releases/latest).

This repo only holds the release files and `version.json`, which the app reads to check for updates. The source code is private.

Local translation models, when added, are OPUS-MT (Helsinki-NLP), licensed CC-BY 4.0.
